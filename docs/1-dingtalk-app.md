# 第 1 步：钉钉开放平台建应用（约 10 分钟）

目标：拿到 **AppKey（Client ID）** 和 **AppSecret（Client Secret）**，并把回调地址加入白名单。

> 需要钉钉企业管理员账号。控制台偶尔改版，入口名称以实际为准，找同名功能即可。

## 1. 创建企业内部应用

1. 浏览器打开 [钉钉开发者后台](https://open-dev.dingtalk.com)，用管理员钉钉账号扫码登录
2. **应用开发 → 创建应用**，应用名称随意（会显示在扫码授权页上，建议填公司名，如「XX公司 SSO」），填简介和图标
3. 创建完成后进入应用详情

## 2. 拿凭证

左侧 **凭证与基础信息**：

- **Client ID**（旧称 AppKey）
- **Client Secret**（旧称 AppSecret）——点查看并复制，**只此一份，交给服务运营时注意保密**

## 3. 开权限

左侧 **权限管理**，搜索「个人信息」：

- 开通 **「通讯录个人信息读权限」（Contact.User.Read）**

> 没有这个权限，登录时会拿不到用户信息报错。

## 4. 配回调白名单（关键）

左侧 **安全设置 → 重定向 URL（回调地址）**，新增一条
（从你的租户地址打开本文档时，下面会直接是你的真实回调地址）：

```
{{CALLBACK_URL}}
```

> 必须一字不差（https、路径 `/cb`）。填错的话扫码后钉钉会报「重定向地址错误」。

## 5. 发布应用

**版本管理与发布**：确保应用有一个已发布（上线）的版本。

> 应用处于「开发中」未发布时，部分组织扫码会提示应用未上线或无权限。发布企业内部应用仅对本企业可见，不影响安全。

## 6. 顺手记下企业 ID（corpId）

钉钉管理后台（oa.dingtalk.com）→ 企业信息 → **企业 ID**，形如 `dingxxxxxxxxxxxxxxxx`。

把它和服务运营提供的登记信息一起交过来，用于登录准入白名单。
（也可以先不填，运营开通时用 `["*"]` 放开，你首次登录成功后从审计日志取到真实 corpId 再锁紧——两种方式都行。）

## ✅ 完成后你应有

| 项 | 去向 |
|---|---|
| Client ID / Client Secret | 交给服务运营开通租户 |
| 回调白名单一条 `/cb` 地址 | 已保存在钉钉应用里 |
| 企业 ID（corpId，可选） | 一并交给运营 |
